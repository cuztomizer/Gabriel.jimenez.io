# gabrieljimenez.io

Source for [Gabriel Jimenez](https://gabrieljimenez.io)'s personal portfolio, published as a static GitHub Pages site.

The site is served from the repository root (`index.html`, `css/`, `js/`, and `assets/`). `CNAME` sets the custom domain to `gabrieljimenez.io`. `.nojekyll` turns off Jekyll processing so Pages serves the files as-is.
